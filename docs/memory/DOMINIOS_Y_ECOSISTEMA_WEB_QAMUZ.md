# Memoria — Dominios y ecosistema web de QAMUZ

Fecha de registro: 18 de agosto de 2026

## Dominios confirmados

### qamuz.ai

Dominio principal de la plataforma tecnológica y del SaaS de QAMUZ.

Uso previsto:

- SaaS principal de QAMUZ AI.
- Maestro, generación musical y herramientas inteligentes.
- QAMUZ Studio, QAMUZ Master y QAMUZ MIDI.
- Acceso de usuarios, suscripciones y servicios de creación musical.
- API y servicios relacionados con Gen Audius.

Subdominios preliminares que se evaluarán:

- `studio.qamuz.ai` — QAMUZ Studio.
- `api.qamuz.ai` — API, Maestro y servicios del backend.
- `models.qamuz.ai` — servicios de modelos de Gen Audius, solamente si la arquitectura lo requiere.

El dominio fue adquirido mediante Cloudflare.

### qamuz.com

Sitio público construido con WordPress.

Uso previsto:

- Blog informativo.
- Noticias y novedades de QAMUZ.
- Tutoriales y contenidos educativos.
- Información sobre artistas y géneros musicales.
- Posicionamiento SEO.
- Enlaces y llamadas a la acción hacia el SaaS mediante opciones como “Crear con QAMUZ”.

### genaudius.com

Sitio corporativo de Gen Audius construido con WordPress.

Uso previsto:

- Presentación de la empresa.
- Tecnología e investigación.
- Licencias y propiedad intelectual.
- Alianzas y relaciones institucionales.
- Información para prensa e inversionistas.
- Documentación corporativa.
- Conexión institucional con QAMUZ AI y qamuz.com.

## Principio de organización

Los tres dominios compartirán una identidad visual coherente, pero tendrán funciones claramente separadas:

1. `qamuz.ai`: producto, aplicación y servicios inteligentes.
2. `qamuz.com`: contenido público, comunidad, educación y captación orgánica.
3. `genaudius.com`: presencia corporativa, tecnología, licencias y alianzas.

## Secuencia futura de implementación

1. Definir el mapa definitivo de dominios y subdominios.
2. Revisar todos los servicios DNS existentes antes de realizar cambios.
3. Configurar correo, HTTPS, seguridad y redirecciones.
4. Conectar `qamuz.ai` con el SaaS de QAMUZ AI.
5. Instalar y configurar WordPress para `qamuz.com`.
6. Instalar y configurar WordPress para `genaudius.com`.
7. Unificar identidad visual, navegación cruzada y analítica.
8. Conectar llamadas a la acción del blog y del sitio corporativo con el SaaS.

## Precauciones

- No compartir claves, tokens ni códigos de Cloudflare en conversaciones o documentos públicos.
- No modificar DNS sin preparar primero un inventario de registros y servicios activos.
- Evitar que las configuraciones de WordPress interfieran con el SaaS o sus APIs.
- Mantener separados los entornos corporativo, editorial y de producto.

## Estado

Plan registrado para desarrollarlo más adelante. No iniciar todavía cambios de DNS, instalaciones de WordPress ni despliegues hasta que se retome expresamente esta fase.
